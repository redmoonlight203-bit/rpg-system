# Primer tileset YUGEN

`yugen-exteriores-oscuro-v1.jpg` conserva exactamente los bytes del adjunto `1000244330.png` proporcionado por el usuario para integrarlo en YUGEN. El contenido real es JPEG de 1536×1536, por eso cambia únicamente la extensión.

Procedencia: imagen aportada por el GM. No se ha establecido el autor original ni una licencia de terceros. No se atribuye a un proveedor ni se declara dominio público.

Manifiesto y recortes versionados: `lib/tileset-yugen.ts`. El paquete se referencia por URL para no guardar copias dentro de cada encuentro. Cambiar la imagen o sus recortes requiere un ID/archivo de versión nuevo para no alterar mapas guardados.
