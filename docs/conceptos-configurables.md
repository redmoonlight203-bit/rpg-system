# Conceptos configurables · guía rápida para el GM

Todo se crea en el Yunque, sin JSON ni SQL. Una creación se lo da a un personaje como habilidad o pasiva; con
«herencia» por linaje o clan, a todos los que cumplan el requisito.

| Quiero… | En el Yunque |
|---|---|
| Una criatura inmune al fuego (pero no a Quemadura) | Habilidad → acción → Uso «Rasgo siempre activo» → Defensas: Daño «Fuego», modo «Sin daño» |
| Inmunidad a un estado o a la mente | Misma sección: columna Estado o Categoría (control, miedo, ilusión…) |
| Un objeto que protege mientras se lleva | Objeto equipable → acción «Rasgo siempre activo» → duración «Mientras esté equipada» |
| +2 Fatiga máxima en una capa | Objeto con ranura → «Mientras esté equipado» → Fatiga máxima |
| Un estado nuevo (Pánico, Sopor…) | Acción «Estado» → «Estado propio» → añadir primitivas |
| Una habilidad que atraviesa inmunidades | Acción → «Mente e inmunidades» → «Atraviesa inmunidades» |
| Un rasgo que potencia otras técnicas (Bioelectricidad) | Rasgo siempre activo → «Concede un rasgo combinable» → recursos y potenciadores |
| Un mordisco en lugar de puñetazo | Rasgo siempre activo → «Sustituye un concepto básico» → Ataque desarmado |
| Una guardia distinta | Igual, eligiendo «Guardia» |
| La animación de un arma | Acción de daño → «Esqueleto de la animación» (o «Nuevo esqueleto», solo el GM) |

Prioridad cuando hay varios conceptos: personaje → objeto equipado → habilidad. Si varios componentes de una técnica
reaccionan con el mismo estado (Mojado), reacciona el que aparece primero en la definición del estado.
